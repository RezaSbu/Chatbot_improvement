# Chatbot Improvement 🤖

Experiments and improvements for **conversational AI chatbots**.

## Overview

This repository contains research and experiments focused on improving chatbot performance — covering context handling, retrieval-augmented generation (RAG), and prompt engineering. It evolved into the more complete projects in my profile:

- [**Neurabot**](https://github.com/RezaSbu/Neurabot) — full-stack RAG chatbot
- [**MO_BOT**](https://github.com/RezaSbu/MO_BOT) — React + TypeScript + Gemini chatbot
- [**NeuraQueen**](https://github.com/RezaSbu/NeuraQueen) — AI customer assistant

## Topics Covered

- Context management in multi-turn conversations
- Retrieval-Augmented Generation (RAG)
- Prompt engineering techniques
- Evaluation of chatbot responses

## Status

Early-stage experiments. The production-grade implementations live in the repositories above.
